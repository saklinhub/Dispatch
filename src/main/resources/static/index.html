Operational Guarantees & Features

Transactional Outbox Pattern

Notifications and Outbox events are written in a single ACID transaction, eliminating dual-write loss even during broker failure.

Multi-Channel Strategies

Pluggable delivery for SMTP Email, Twilio SMS REST API, and persistent user In-App Inboxes.

Timezone Quiet Hours

Evaluates recipients' IANA timezones and window intervals (e.g. 22:00-07:00), deferring dispatches automatically.

Idempotency Fingerprinting

SHA-256 payload matching and atomic database locks prevent duplicate sends and replay cached responses seamlessly.
